# Trevor Nielsen — Portfolio Site

Personal site for [trevornielsen.com](https://trevornielsen.com). Currently a temporary handmade-style placeholder page while the full portfolio is rebuilt in public (scaffolded from `template-marketing-sites`).

Stack: Next.js (App Router) · TypeScript · Tailwind CSS v4 · shadcn.

## Develop

```bash
npm install
npm run dev
```

Then open http://localhost:3000. `npm run build` for a production build.
